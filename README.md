# Soft Cyber — Personal Cybersecurity Portfolio

A bright, minimal, retro-futuristic personal portfolio website designed for a Cybersecurity enthusiast exploring **Blue Team**, **Red Team**, and **Purple Team** security.

Built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** — zero frameworks, zero build tools, and 100% ready for **GitHub Pages**.
